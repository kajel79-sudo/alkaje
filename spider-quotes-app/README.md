# Spider-Quotes 🕷️

스파이더맨(Spider-Man) 명언을 랜덤으로 보여주는 감성 카드형 웹 앱입니다.
순수 HTML/CSS/JavaScript(바닐라)만으로 만들어졌으며, 별도의 빌드 과정 없이
`index.html`을 브라우저에서 열기만 하면 바로 실행됩니다.

## 실행 방법

`index.html` 파일을 더블클릭해서 브라우저로 열면 됩니다. (별도 서버/설치 불필요)

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 랜덤 명언 카드 | 20개의 스파이더맨 명언 중 하나를 무작위로 보여주고, 부드러운 페이드 애니메이션으로 전환 |
| 테마 변경 | 하단 "테마" 버튼 → 바텀시트에서 5가지 배경 테마(선셋/나이트/오션/포레스트/미니멀) 선택, `localStorage`에 저장되어 재방문 시에도 유지 |
| 공유 / 복사 | "공유" 버튼 클릭 시 모바일에서는 Web Share API로 공유 시트가 뜨고, 지원하지 않는 환경(대부분의 PC 브라우저)에서는 클립보드로 자동 복사 |
| 모바일 반응형 | 375px~430px 모바일 화면 폭에 맞춘 레이아웃 최적화 |

## 파일 구조

```text
spider-quotes-app/
├── index.html   # 페이지 구조 (카드, 버튼, 테마 바텀시트)
├── style.css    # CSS 변수 기반 테마 스타일링 및 애니메이션
├── data.js      # 명언 20개 데이터 (영어 원문 + 한글 번역 + 인물/작품/주제)
└── app.js       # 렌더링, 테마 전환, 공유/복사 등 핵심 로직
```

각 파일 상단과 함수 위에 한글 주석으로 "왜 이렇게 작성했는지"를 설명해 두었으니,
바이브코딩 입문자도 코드를 따라 읽으며 동작 원리를 이해할 수 있습니다.

## 데이터 구조 (`data.js`)

```typescript
interface QuoteItem {
  id: number;        // 명언 고유 번호
  quote_en: string;  // 영어 원문
  quote_ko: string;  // 한글 번역
  speaker: string;   // 대사를 말한 캐릭터
  movie: string;     // 출처 작품
  theme: string;     // 명언의 주제 태그 (예: 책임감, 희망, 성장 등)
}
```

## 이번 작업 요약

- 기술명세서(`Spider_Quotes_Technical_Specification.md`)를 기반으로 프로젝트를 처음부터 구현
- `index.html` / `style.css` / `data.js` / `app.js` 4개 파일 구조로 작성
- 스파이더맨 명언 20개(원문+번역+인물+작품+주제) 데이터 작성
- CSS 커스텀 프로퍼티(`--bg-gradient`, `--font-color`, `--card-bg`)로 5종 테마 전환 구현, `localStorage`로 선택한 테마 유지
- 랜덤 명언 페이드 전환, 클립보드 복사, Web Share API 연동 구현
- 브라우저에서 실제 동작 확인 완료
- 이번 최초 구현에서 별도로 수정한 버그는 없으며, 문법 검사(`node --check`)와 브라우저 실행 테스트를 통과함
