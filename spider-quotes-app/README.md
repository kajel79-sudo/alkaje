# Spider-Quotes 🕷️

스파이더맨(Spider-Man) 명언을 랜덤으로 보여주는 감성 카드형 웹 앱입니다.
순수 HTML/CSS/JavaScript(바닐라)만으로 만들어졌으며, 별도의 빌드 과정 없이
`index.html`을 브라우저에서 열기만 하면 바로 실행됩니다.

## 실행 방법

`index.html` 파일을 더블클릭해서 브라우저로 열면 됩니다. (별도 서버/설치 불필요)

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 랜덤 명언 카드 | 20개의 스파이더맨 명언 중 하나를 무작위로 보여주고, 부드러운 페이드 애니메이션으로 전환 |
| 테마 변경 | 하단 "테마" 버튼 → 바텀시트에서 5가지 배경 테마(선셋/나이트/오션/포레스트/미니멀) 선택, `localStorage`에 저장되어 재방문 시에도 유지 |
| 다국어 지원 | 하단 "언어" 버튼 → 한국어/English/日本語 선택. 명언 번역문, 주제 태그, 버튼/모달 문구가 전부 전환되며 `localStorage`에 저장되어 재방문 시에도 유지. 저장된 값이 없으면 브라우저 언어를 자동 감지 |
| 공유 / 복사 | "공유" 버튼 클릭 시 모바일에서는 Web Share API로 공유 시트가 뜨고, 지원하지 않는 환경(대부분의 PC 브라우저)에서는 클립보드로 자동 복사 |
| 디바이스별 반응형 레이아웃 | 모바일(~700px)은 화면 전체를 채우는 엣지투엣지 레이아웃, 태블릿(701~1023px)/데스크탑(1024px~)은 화면 중앙에 떠 있는 카드 레이아웃으로 자동 전환 |

## 파일 구조

```text
spider-quotes-app/
├── index.html   # 페이지 구조 (카드, 버튼, 테마/언어 바텀시트)
├── style.css    # CSS 변수 기반 테마 스타일링, 반응형 레이아웃, 애니메이션
├── data.js      # 명언 20개 데이터 (영어 원문 + 한글/일본어 번역 + 인물/작품/주제)
├── i18n.js      # UI 문구 및 주제 태그의 한국어/영어/일본어 번역 사전
└── app.js       # 렌더링, 테마·언어 전환, 공유/복사 등 핵심 로직
```

각 파일 상단과 함수 위에 한글 주석으로 "왜 이렇게 작성했는지"를 설명해 두었으니,
바이브코딩 입문자도 코드를 따라 읽으며 동작 원리를 이해할 수 있습니다.

## 데이터 구조 (`data.js`)

```typescript
interface QuoteItem {
  id: number;        // 명언 고유 번호
  quote_en: string;  // 영어 원문 (항상 카드 메인 문장으로 표시)
  quote_ko: string;  // 한글 번역 (언어가 한국어일 때 부제로 표시)
  quote_ja: string;  // 일본어 번역 (언어가 일본어일 때 부제로 표시)
  speaker: string;   // 대사를 말한 캐릭터
  movie: string;     // 출처 작품
  theme: string;     // 명언의 주제 태그 (한국어 키, 예: 책임감, 희망, 성장 등)
                      // 화면 표시 시 i18n.js의 themeTagTranslations로 번역됨
}
```

## 작업 이력

### v1 — 최초 구현
- 기술명세서(`Spider_Quotes_Technical_Specification.md`)를 기반으로 프로젝트를 처음부터 구현
- `index.html` / `style.css` / `data.js` / `app.js` 4개 파일 구조로 작성
- 스파이더맨 명언 20개(원문+번역+인물+작품+주제) 데이터 작성
- CSS 커스텀 프로퍼티(`--bg-gradient`, `--font-color`, `--card-bg`)로 5종 테마 전환 구현, `localStorage`로 선택한 테마 유지
- 랜덤 명언 페이드 전환, 클립보드 복사, Web Share API 연동 구현
- 문법 검사(`node --check`)와 브라우저 실행 테스트를 통과함 (별도로 수정한 버그 없음)

### v2 — 반응형 레이아웃 & 다국어 지원 추가
- 디바이스별 반응형 레이아웃: 모바일은 엣지투엣지, 태블릿/데스크탑은 중앙 정렬 카드 레이아웃(`.app-shell`)으로 분기
- 다국어 지원(한국어/영어/일본어) 추가: `i18n.js` 신설, 명언 데이터에 `quote_ja` 필드 추가
- 화면의 모든 버튼/모달 문구를 `data-i18n` 속성 기반으로 자동 번역하는 `applyTranslations()` 구현
- 테마 선택과 언어 선택 바텀시트가 CSS 클래스(`.sheet-modal`, `.bottom-sheet`, `.option-grid` 등)를 공유하도록 리팩터링
- `node --check`로 3개 스크립트 문법 검증, VM 컨텍스트로 명언 20개·테마 태그 13종의 번역 누락 여부 검증, 브라우저 실행 테스트 통과
